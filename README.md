## テーマ
プロスポーツチームを核とした都市の回遊性と地域経済の連動性分析
— 横浜DeNAベイスターズ「CLUB BAYSTARS」加盟店の空間分布に着目して —

## 概要/Abstract
本研究は、横浜DeNAベイスターズの地域密着型プロジェクト「CLUB BAYSTARS」の加盟店データを可視化・分析することで、スタジアムから街へと波及するプロスポーツの経済的・空間的影響を明らかにすることを目的とした。分析の結果、加盟店はスタジアム近隣の飲食店のみならず、広域の生活サービス業にまで波及しており、スポーツが都市の多角的な回遊性を生むハブとなっていることが示唆された。

## Introduction
横浜市は「コミュニティボールパーク」化構想を掲げ、横浜スタジアムを中心とした街づくりを推進してきた。その象徴的な取り組みが、地域店舗が球団を応援し、ファンを優遇する「CLUB BAYSTARS」制度である。しかし、これらの店舗が都市空間の中でどのように分布し、どのような役割を果たしているのか、網羅的なデータに基づく分析は十分ではない。本研究では、これらを可視化することで、スポーツによる都市活性化の実態を考察する。



## Methods（方法）
データソース: 横浜DeNAベイスターズが配布・公開している公式加盟店リストを使用。

データクレンジング: 全362件の店舗情報を抽出し、「飲食店」「バー」「小売」「美容・サービス」「観光・レジャー」「スクール・ライフスタイル」の6カテゴリに分類。

空間分析: 各店舗の住所情報をジオコーディングし、Google My Mapsを活用してプロット。横浜スタジアムからの距離および業種別の空間分布を視覚化した。

## Discussion（考察）
回遊性の創出: 試合当日のチケット提示を条件とする特典（ドリンク一杯無料など）は、スタジアムから駅・街への歩行流動を強力に誘発している。

勝利との連動性: 「勝利翌日割引」を設定している店舗の存在は、チームの勝敗という情緒的価値が、翌日の地域経済の活性化に直接的な影響を与える感情連動型経済を構築していると言える。

都市機能への波及: ライフスタイル系店舗の加盟は、プロスポーツが単なるエンターテインメントに留まらず、地域住民のアイデンティティの形成に寄与していることを示している。

## Conclusion（結論）
本研究による可視化の結果、「CLUB BAYSTARS」はスタジアム周辺の経済効果のみならず、都市全体の回遊性を高め、地域住民とチームの持続的な関係性を構築するインフラとして機能していることが明らかになった。今後の課題は、これらの店舗を利用するファンの実際の属性や移動ログデータを組み合わせ、より動的な回遊パターンの解析を行うことである。
