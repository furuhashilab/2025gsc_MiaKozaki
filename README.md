# 2025gsc_MiaKozaki
2025年ゼミ論
## テーマ
プロスポーツチームを核とした都市の回遊性と地域経済の連動性分析
— 横浜DeNAベイスターズ「CLUB BAYSTARS」加盟店の空間分布に着目して —

## 概要/Abstract
本研究は、横浜DeNAベイスターズの地域加盟店制度「CLUB BAYSTARS」に着目し、スポーツが都市の経済活動へ与える影響を空間的に分析したものである。既存の公式サイトにおける情報の検索性の低さがファンの回遊を阻害しているという仮説に基づき、全362件の加盟店情報を独自にデジタルデータ化し、GISを用いた可視化マップを構築した。分析の結果、業種ごとの空間的集積傾向が明らかになった。本研究は、現状の静的な分布の可視化を達成したが、実測の人流データとの連動に課題を残しており、これを次年度の卒業論文における展望とする。

## Introduction
1.1 研究の背景

横浜スタジアムを中心としたコミュニティボールパーク化構想により、スポーツは都市の活性化において重要な役割を担っている。そのソフト面の核となるのが、地域店舗が球団を応援し、ファンが優待を受けられる「CLUB BAYSTARS」制度である。

1.2 問題意識：情報の摩擦

しかし、公式サイトの店舗情報はリスト形式に留まり、現在地からの検索や直感的な位置把握が困難である。このような情報の使いにくさは、ファンのついで寄りや寄り道といった経済行動を阻害する情報の摩擦となっている。

1.3 研究の目的

本研究では、散在する店舗情報をGIS上に再構築することで、情報のアクセシビリティを向上させ、スポーツによる都市の回遊性がどのようにデザインされているかを実証的に可視化することを目的とする



## Methods（方法）
2.1 データの構築（クレンジング）

Webサイトより、加盟店全362件の情報を抽出した。店舗名、住所、営業時間、特典内容を一件ずつ精査し、以下の6カテゴリに分類した。

飲食店

バー

小売

美容・サービス

観光・レジャー

スクール・ライフスタイル

2.2 GISを用いた可視化

抽出した住所データに対しジオコーディングを行い、Google My Maps上にプロットした。業種ごとにシンボルカラーを設定し、スタジアムからの距離およびエリアごとの集積度を視覚的に分析可能な状態にした。

3.1 空間的分布の特徴

全体像: 横浜市中区・西区に集中しているが、沖縄や山形など全国各地に応援拠点が点在し、プロスポーツが広域なコミュニティのハブとなっている。

関内・伊勢佐木町エリア: 飲食店の圧倒的な集積が見られ、試合終了後の祝杯を支えるインフラとなっている。

元町・石川町エリア: 美容院や歯科医院といった生活密着型サービスが点在し、試合日以外の日常的な接点が形成されている。

3.2 業種構成比

全362件のうち、飲食店が約53%を占める一方、美容・サービス業が約16%、小売が約10%を占め、スポーツの応援が飲食以外の多様な消費行動と結びついていることが判明した。


## Discussion（考察）
情報をリストから地図へ再定義することで、ファンの心理的ハードルを下げ、偶然の寄り道を誘発する基盤を構築した。これはデータで人の行動をデザインする試みである。

### 本研究の限界（Limitations）

本研究には以下の課題が残されている。

供給側の視点のみの分析: 店舗の配置は見えたが、実際にファンがそこを歩いているかという需要側の実態を証明できていない。

定量的効果の不足: 特典利用による実際の経済波及効果を数値化するまでには至っていない。

## Conclusion（結論）
本研究により、362件の加盟店ネットワークはスタジアムの熱気を都市の隅々まで運ぶ「血管」の役割を果たしていることが視覚的に証明された。情報のUX改善は、地域振興の実効性を高めるための不可欠なプロセスである。
